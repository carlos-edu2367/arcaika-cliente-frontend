Auditoria completa realizada em 2026-06-05. Foram identificados **22 problemas** distribuídos em:

## Riscos Remanescentes

1. **Testes E2E não executados** — dependem de `npm install -D @playwright/test && npx playwright install`. Requerem `npm run dev` em paralelo ou CI configurado.
2. **Categorias sem ícones reais** — Home usa a primeira letra do nome como ícone. Funciona mas não é ideal; recomenda-se adicionar ícones de categoria via API ou mapeamento local.
3. **URL de pagamento sem validação** — `window.location.href = url_pagamento` aceita qualquer URL retornada pelo backend sem checar que é HTTPS. Risco baixo (depende de comprometimento do backend), mas recomendável adicionar `url.startsWith('https://')` antes do redirect.
4. **RequireAuth usa axios vanilla** — Funcional, mas separado do interceptor configurado. Não afeta comportamento em produção (URL hardcoded para GCR está correta).

## Próximos Passos Recomendados

1. `npm install -D @playwright/test && npx playwright install` + rodar `npm run test:e2e`
2. Adicionar ícones SVG reais para categorias (substituir `cat.nome.charAt(0)`)
3. Validar URL de pagamento antes do redirect: `if (!res.url_pagamento.startsWith('https://')) throw new Error(...)`
4. Considerar migrar `BrowserRouter` → `createBrowserRouter` para usar `ScrollRestoration` nativo
